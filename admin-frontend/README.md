# Smart Barber - Admin Panel

React + Vite admin panel for platform administrators to manage salons, owners, and approvals.

## Setup

```bash
npm install
cp .env.example .env   # fill in your values
npm run dev
npm run build          # production build
```

## Environment Variables

See `.env.example`.

| Variable            | Description      |
|---------------------|------------------|
| `VITE_API_BASE_URL` | Backend API URL  |
